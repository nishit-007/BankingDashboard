# 🏦 Banking Dashboard – End-to-End Data Analysis Project

An end-to-end Business Intelligence project developed using **MySQL** and **Microsoft Power BI** to analyse customer banking data. The project demonstrates the complete analytics workflow, including data extraction, cleaning, exploratory data analysis (EDA), and interactive dashboard development for business decision-making.

---

## 📌 Project Overview

The objective of this project is to analyse customer banking behaviour by evaluating loans, deposits, account balances, and customer demographics. The dashboard provides meaningful insights that help banks understand customer financial patterns and support strategic business decisions.

---

## 🎯 Business Objectives

- Analyse customer deposits, loans, and account balances.
- Understand customer demographics and income distribution.
- Identify relationships between different banking products.
- Monitor key financial metrics through interactive dashboards.
- Enable data-driven decision-making for banking operations.

---

## 🔄 Project Workflow

**Dataset → MySQL → Data Cleaning & Preparation → Exploratory Data Analysis (EDA) → Power BI Dashboard**

---

## 📊 Dataset Information

- **Database:** MySQL
- **Number of Columns:** 24
- **Dashboard Tool:** Microsoft Power BI
- **Data Processing:** SQL & Power Query

---

## 🔧 Data Cleaning & Preparation

The dataset was cleaned and transformed before analysis using SQL and Power Query.

### Transformations Performed

- Categorised customer income into:
  - Low Income
  - Middle Income
  - High Income

- Standardised categorical fields such as:
  - Gender
  - Nationality
  - Banking Relationship

- Converted branch codes into readable branch names.

- Mapped gender codes:
  - **1 → Male**
  - **2 → Female**

- Created conditional columns for customer segmentation.

## 💡 Key Insights

- Customers with higher deposits generally maintain larger balances across multiple account types.
- A strong positive correlation exists between:
  - Bank Deposits
  - Checking Accounts
  - Saving Accounts
  - Foreign Currency Accounts
- Higher-income customers tend to utilise more banking products.
- Customer segmentation helps identify profitable customer groups for targeted financial services.
